# Muestras locales

La fotografía `objeto.jpg` preexistente se conservó en esta PC y se excluye de Git. El comando `test-model` puede recibir `--image` o generar una imagen determinista para su smoke técnico cuando no existe una muestra privada. Una imagen generada sólo comprueba que los embeddings sean finitos; no evalúa reconocimiento de herramientas reales.
