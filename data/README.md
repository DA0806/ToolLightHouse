# Datos fuera de Git

Preparar localmente `references/<class_id>/`, `calibration/`, `evaluation/<class_id>/` y la galería generada. No se distribuyen fotos personales, fondo de bandeja, embeddings ni datos de evaluación en el repositorio. Ver `docs/DATA.md` para separación de conjuntos y `docs/COMMANDS.md` para construir/calibrar/evaluar.

El inventario de ejemplo y la configuración de software sí se encuentran en `config/`. Los nueve nombres/ubicaciones definitivos deben completarse con el equipo antes de conectar LEDs físicos.
